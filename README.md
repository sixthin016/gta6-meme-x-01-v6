## What it is

`meme.png` (1080x1080) is a dense fake-document meme generated by a
deterministic Python script — no AI image model, no network, no clock.

## How to run

```sh
python3 gen_meme.py
```

## Files

- `gen_meme.py` — the generator (Pillow, DejaVu fonts)
- `meme.png` — the meme, 1080x1080
- `meme-480.png` — the same render at 480x480 (judge size)
- `main.ts` — copies `POST.json` to `/output`
- `POST.json` — link to the X post carrying this meme
- `caption.txt` / `title.txt` — the X post text and title
